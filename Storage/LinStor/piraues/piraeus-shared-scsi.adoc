= Piraeus 

Allows you use a shared scsi luns, across 2+ node clusters.


== Deploy operator

.install.sh
[source,bash]
----
oc new-project piraeus-datastore
oc apply --server-side -f "https://github.com/piraeusdatastore/piraeus-operator/releases/latest/download/manifest.yaml"
----

== Setup Satellite


.satelite.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorSatelliteConfiguration
metadata:
  name: pure-san-storage-satellites
spec:
  podTemplate:
    spec:
      initContainers:
        - $patch: delete
          name: drbd-module-loader  
      volumes:
        - $patch: delete
          name: lib-modules
      automountServiceAccountToken: true
EOF
----

== Deploy Cluster

.cluster.sh
[source,bash]
----
oc apply -f - << EOF
apiVersion: piraeus.io/v1
kind: LinstorCluster
metadata:
  name: linstorcluster
spec:
  csiController:
    enabled: true
    podTemplate:
      spec:
        automountServiceAccountToken: true
  csiNode:
    enabled: true
    podTemplate:
      spec:
        automountServiceAccountToken: true
EOF
----

== Create Storage Class

.storageclass.sh
[source,bash]
----
oc appl -f - <<EOF
kind: StorageClass
apiVersion: storage.k8s.io/v1
metadata:
  name: piraeus-storage
  annotations:
    storageclass.kubevirt.io/is-default-virt-class: 'true'
provisioner: linstor.csi.linbit.com
parameters:
  linstor.csi.linbit.com/allowRemoteVolumeAccess: 'true'
  linstor.csi.linbit.com/autoPlace: '1'
  linstor.csi.linbit.com/layerList: STORAGE
  linstor.csi.linbit.com/placementCount: '1'
  linstor.csi.linbit.com/storagePool: pool1
reclaimPolicy: Delete
allowVolumeExpansion: true
volumeBindingMode: WaitForFirstConsumer
----

== Configuring shared LUN

Create Volume Group, across all shared scsi luns:

.First Node: (Openshift Cluster node)
[source,bash]
----
pvcreate /dev/mapper/mpatha
vgcreate vg_piraeus --shared --setpersist y --setlockargs persist,notimeout /dev/mapper/mpatha
vgscan
----

.Second Node:
[source,bash]
----
vgscan
vgchange --lockstart vg_piraeus
----
