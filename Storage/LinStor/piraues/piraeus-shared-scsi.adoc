= Piraeus 

Allows you to use shared scsi luns, across 2+ node clusters. Luns can be direct attached, fibre channel or iscsi.

== Deploy operator

.install.sh
[source,bash]
----
oc new-project piraeus-datastore
oc apply --server-side -f "https://github.com/piraeusdatastore/piraeus-operator/releases/latest/download/manifest.yaml"
----

=== Setup security

Openshift specific tweaks:

.policy.sh
[source,bash]
----
oc adm policy add-scc-to-user privileged -z linstor-satellite-sa -n piraeus-datastore
oc adm policy add-scc-to-user privileged -z linstor-csi-controller-sa -n piraeus-datastore
oc adm policy add-scc-to-user privileged -z linstor-csi-node-sa -n piraeus-datastore
----

.roles.sh
[source,bash]
----
oc apply -f - <<EOF
kind: ClusterRole
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: linstor-csi-node-pv-patch
rules:
  - verbs:
      - get
      - list
      - watch
    apiGroups:
      - ''
    resources:
      - persistentvolumes
---
kind: ClusterRoleBinding
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: linstor-csi-node-pv-patch-binding
subjects:
  - kind: ServiceAccount
    name: linstor-csi-node
    namespace: piraeus-datastore
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: linstor-csi-node-pv-patch
EOF
----

=== Setup Satellite


.satelite.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorSatelliteConfiguration
metadata:
  name: pure-san-storage-satellites
spec:
  podTemplate:
    spec:
      initContainers:
        - $patch: delete
          name: drbd-module-loader  
      volumes:
        - $patch: delete
          name: lib-modules
      automountServiceAccountToken: true
EOF
----

NOTE: To get the correct image (first image referenced in next script) do a "oc adm release info $(oc get clusterversion version -o jsonpath='{.status.desired.image}') --image-for=driver-toolkit"

=== Deploy Cluster

.cluster.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorCluster
metadata:
  name: linstorcluster
spec:
  csiController:
    enabled: true
    podTemplate:
      spec:
        automountServiceAccountToken: true
  csiNode:
    enabled: true
    podTemplate:
      spec:
        automountServiceAccountToken: true
EOF
----

Create LVM filters to include "/dev/mapper/mpath*"

.lvm filter
[source,bash]
----

  labels:
    machineconfiguration.openshift.io/role: master
  name: 99-master-lvm-filter
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
      - contents:

        mode: 420
        path: /etc/lvm/lvm.conf.d/99-linstor-filter.conf

Create Volume Group, across all shared scsi luns:

.*First Node:* (Openshift Cluster node)
[source,bash]
----
pvcreate /dev/mapper/mpatha
vgcreate vg_piraeus /dev/mapper/mpatha
vgscan
----

.Second Node:
[source,bash]
----
vgscan
vgchange -ay vg_piraeus
----

=== Configure Storage Pool

.storage-pool.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorSatelliteConfiguration
metadata:
  name: shared-scsi-pool
spec:
  storagePools:
    - name: scsi-shared-vg
      lvmPool:
        volumeGroup: "vg_piraeus"
        sharedSpace: "san-scsi-cluster-1" # Must be identical on all nodes sharing the LUN
EOF
----


=== Create Storage Class

.storageclass.sh
[source,bash]
----
oc apply -f - <<EOF
kind: StorageClass
apiVersion: storage.k8s.io/v1
metadata:
  name: piraeus-shared-virt
  annotations:
    storageclass.kubevirt.io/is-default-virt-class: 'true'
provisioner: linstor.csi.linbit.com
parameters:
  linstor.csi.linbit.com/allowRemoteVolumeAccess: 'true'
  linstor.csi.linbit.com/autoPlace: '1'
  linstor.csi.linbit.com/layerList: STORAGE
  linstor.csi.linbit.com/placementCount: '1'
  linstor.csi.linbit.com/storagePool: scsi-shared-vg
reclaimPolicy: Delete
allowVolumeExpansion: true
volumeBindingMode: Immediate

EOF
----

.snapshotclass.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: snapshot.storage.k8s.io/v1
kind: VolumeSnapshotClass
metadata:
  name: piraeus-rwx-snapshot-class
driver: linstor.csi.linbit.com
deletionPolicy: Delete
parameters:
  # Allows LINSTOR to ignore active attachments during a snapshot sequence
  allow-active-multi-node: "true"
EOF
----

== Node Preparation

We need to install dm-snapshot module:

NOTE: Adapt master/worker roles as required.

.modprobe.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: master
  name: 99-master-dm-snapshot
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
      - contents:
          source: data:,dm-snapshot%0A
        mode: 420
        overwrite: true
        path: /etc/modules-load.d/dm-snapshot.conf
EOF
----

NOTE: Only for verification, Linstor/Piraeus is a recognized CSI driver in OpenShift, so the StorageProfile should be correct:

.StorageProfile
[source,yaml]
----
apiVersion: cdi.kubevirt.io/v1beta1
kind: StorageProfile
metadata:
  name: piraeus-storage
spec:
  claimPropertySets:
    - accessModes:
        - ReadWriteMany
      volumeMode: Block
    - accessModes:
        - ReadWriteOnce
      volumeMode: Block
    - accessModes:
        - ReadWriteOnce
      volumeMode: Filesystem
    - accessModes:
        - ReadOnlyMany
      volumeMode: Block
    - accessModes:
        - ReadOnlyMany
      volumeMode: Filesystem
  cloneStrategy: snapshot
  dataImportCronSourceFormat: pvc
  snapshotClass: piraeus-rwx-snapshot-class
----
