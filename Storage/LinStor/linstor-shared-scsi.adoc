= Linstor

Allows you to use shared scsi luns, across 2+ node clusters. Luns can be direct attached, fibre channel or iscsi.

== Deploy operator

Deploy the Linstor Operator:

.Linstor Project
[source,bash]
----
oc create project linbit-sds
----

.Linstor Credentials
[source,bash]
----
oc create secret docker-registry drbdio-pull-secret \
  --namespace=linbit-sds \
  --docker-server=drbd.io \
  --docker-username=MY_LINBIT_USER \
  --docker-password=MY_LINBIT_PASSWORD
----

Install the Linstor Operator from OpenShift Console.

=== Setup Satellite


=== Deploy Cluster

.cluster.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorCluster
metadata:
  name: linstorcluster
spec:
  csiController:
    enabled: true
    podTemplate:
      spec:
        containers:
          - env:
              - name: FEATURE_GATE_CSI_VOLUME_GROUP_SNAPSHOT
                value: 'true'
            name: csi-snapshotter
EOF
----

== Implementation

=== Configuring shared LUN

NOTE: Enable multipath on Openshift link:../../Mutlipath/Multipathd-service-enable.adoc[Multipath]

Enable mulitpath,create LVM filters to include "/dev/mapper/mpath*" and enable lvmd service.

.multipath.sh
[source,yaml]
----
oc apply -f - << EOF
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: master
  name: 99-master-multipath-lvm
spec:
  config:
    ignition:
      version: 3.4.0
    storage:
      files:
        - contents:
            compression: ""
            source: data:;base64,ZGVmYXVsdHMgewogIHVzZXJfZnJpZW5kbHlfbmFtZXMgeWVzCiAgZmluZF9tdWx0aXBhdGhzIHllcwp9CgpibGFja2xpc3Qgewp9Cg==
          mode: 420
          path: /etc/multipath.conf
        - contents:
            compression: ""
            source: data:;base64,Z2xvYmFsIHsKICB1c2VfbHZtbG9ja2QgPSAxCn0KCmRldmljZXMgewogIGZpbHRlciA9IFsgImF8L2Rldi9tYXBwZXIvbXBhdGguKnwiLCAicnwuKnwiIF0KfQo=
          mode: 420
          path: /etc/lvm/lvmlocal.conf
    systemd:
      units:
        - enabled: true
          name: multipathd.service
        - enabled: true
          name: lvmlockd.service
EOF
----

.For reference Only:
[source,bash]
----

  name: 99-master-multipath-lvm

          }

          }

Create Volume Group, across all shared scsi luns:

.*First Node:* (Openshift Cluster node)
[source,bash]
----
pvcreate /dev/mapper/mpatha
vgcreate vg_piraeus /dev/mapper/mpatha -ff #-ff force if not empty
vgscan
----

.Second Node:
[source,bash]
----
vgscan
vgchange -ay vg_piraeus
----

=== Configure Storage Pool

.storage-pool.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: piraeus.io/v1
kind: LinstorSatelliteConfiguration
metadata:
  name: shared-scsi-pool
spec:
  storagePools:
    - name: scsi-shared-vg
      lvmPool:
        volumeGroup: "vg_piraeus"
        sharedSpace: "san-scsi-cluster-1" # Must be identical on all nodes sharing the LUN
EOF
----


=== Create Storage Class

.storageclass.sh
[source,bash]
----
oc apply -f - <<EOF
kind: StorageClass
apiVersion: storage.k8s.io/v1
metadata:
  name: piraeus-shared-virt
  annotations:
    storageclass.kubevirt.io/is-default-virt-class: 'true'
provisioner: linstor.csi.linbit.com
parameters:
  linstor.csi.linbit.com/allowRemoteVolumeAccess: 'true'
  linstor.csi.linbit.com/autoPlace: '1'
  linstor.csi.linbit.com/layerList: STORAGE
  linstor.csi.linbit.com/placementCount: '1'
  linstor.csi.linbit.com/storagePool: scsi-shared-vg
reclaimPolicy: Delete
allowVolumeExpansion: true
volumeBindingMode: Immediate

EOF
----

.snapshotclass.sh
[source,bash]
----
oc apply -k https://github.com/kubernetes-csi/external-snapshotter//client/config/crd
oc apply -k https://github.com/kubernetes-csi/external-snapshotter//deploy/kubernetes/snapshot-controller
oc patch linstorcluster linstorcluster --type=merge --patch '
spec:
  csiController:
    podTemplate:
      spec:
        containers:
        - name: csi-snapshotter
          env:
          - name: FEATURE_GATE_CSI_VOLUME_GROUP_SNAPSHOT
            value: "true"
'

oc apply -f - <<EOF
apiVersion: groupsnapshot.storage.k8s.io/v1
kind: VolumeGroupSnapshotClass
metadata:
  name: linstor-group-snapshots
driver: linstor.csi.linbit.com
deletionPolicy: Delete
EOF
oc apply -f - << EOF
apiVersion: snapshot.storage.k8s.io/v1
deletionPolicy: Delete
driver: linstor.csi.linbit.com
kind: VolumeSnapshotClass
metadata:
  name: piraeus-snapshot-class
parameters:
  snap.linstor.csi.linbit.com/type: InCluster
EOF
----

== Node Preparation

We need to install dm-snapshot module:

NOTE: Adapt master/worker roles as required.

.modprobe.sh
[source,bash]
----
oc apply -f - <<EOF
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: master
  name: 99-master-dm-snapshot
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
      - contents:
          source: data:,dm-snapshot%0A
        mode: 420
        overwrite: true
        path: /etc/modules-load.d/dm-snapshot.conf
EOF
----

NOTE: Only for verification, Linstor/Piraeus is a recognized CSI driver in OpenShift, so the StorageProfile should be correct:

.StorageProfile
[source,yaml]
----
apiVersion: cdi.kubevirt.io/v1beta1
kind: StorageProfile
metadata:
  name: piraeus-shared-virt
spec:
  claimPropertySets:
    - accessModes:
        - ReadWriteMany
      volumeMode: Block
    - accessModes:
        - ReadWriteOnce
      volumeMode: Block
    - accessModes:
        - ReadWriteOnce
      volumeMode: Filesystem
    - accessModes:
        - ReadOnlyMany
      volumeMode: Block
    - accessModes:
        - ReadOnlyMany
      volumeMode: Filesystem
  cloneStrategy: snapshot
  dataImportCronSourceFormat: pvc
  snapshotClass: piraeus-snapshot-class
----
