= Shared SCSI LUNS

== Enable Multipath on Nodes

WARNING: If 2/3 node cluster use master role, instead of worker role.

.99-worker-multipath.yaml
[code,yaml]
----
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: worker
  name: 99-worker-multipath
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        - contents:
            source: data:,defaults%20%7B%0A%20%20%20%20user_friendly_names%20yes%0A%20%20%20%20find_multipaths%20yes%0A%7D%0A
          mode: 420
          filesystem: root
          path: /etc/multipath.conf
    systemd:
      units:
        - enabled: true
          name: multipathd.service
----

== Configure Storage

=== Configure Volume PV's

.scsi-lun0.yaml
[code,yaml]
----
apiVersion: v1
kind: PersistentVolume
metadata:
  name: lun-0
spec:
  capacity:
    storage: 50Gi                 # Match your precise physical LUN size
  volumeMode: Block               # CRITICAL: Bypasses filesystem node-locking
  accessModes:
    - ReadWriteMany               # Informs the scheduler multiple nodes can connect concurrently
  persistentVolumeReclaimPolicy: Retain
  storageClassName: scsi-shared-das
  local:
    path: /dev/disk/by-id/scsi-35000c50030142f31  # Target path identical on both nodes
  nodeAffinity:
    required:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - bm208.pietersmalan.com
          - bm209.pietersmalan.com
----


.scsi-shared-das-storageclass.yaml
----
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: scsi-shared-das
  annotations:
    storageclass.kubernetes.io/is-default-class: 'true'
provisioner: kubernetes.io/no-provisioner # Instructs OpenShift to look for your static PV
volumeBindingMode: Immediate
----


To determine the devicepaths, do a 'ls /dev/disk/by-id/scsi-*'
