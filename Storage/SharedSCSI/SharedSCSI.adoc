= Shared SCSI LUNS

:toc:
:toc-placement!:

If you have shared SCSI luns on an OpenShift cluster and don't have the ability to utilize a CSI complaint provisioner, then you can pre-allocate the PVs and use no-provioner storage class to simulate a CSI provisioner.

WARNING: SCSI-3 Persistent Reservations (PR) are vital when using a raw block ReadWriteMany (RWX) device across multiple OpenShift nodes. They allow application-level clustering software—like Red Hat High Availability (Pacemaker)—to coordinate writes, manage node quorum, and safely fence off unhealthy nodes to prevent split-brain data corruption. 

TIP: On Dell PowerVault storage arrays (including the ME4 and ME5 series), SCSI-3 Persistent Reservations (PR) are natively supported and permanently enabled by default.

== Enable Multipath on Nodes

WARNING: If 2/3 node cluster use master role, instead of worker role.

.99-worker-multipath.yaml
[source,yaml]
----
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: worker
  name: 99-worker-multipath
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        - contents:
            source: data:,defaults%20%7B%0A%20%20%20%20user_friendly_names%20yes%0A%20%20%20%20find_multipaths%20yes%0A%7D%0A
          mode: 420
          filesystem: root
          path: /etc/multipath.conf
    systemd:
      units:
        - enabled: true
          name: multipathd.service
----

== Configure Storage

=== Configure Volume PVs

.scsi-lun0.yaml
[source,yaml]
----
apiVersion: v1
kind: PersistentVolume
metadata:
  name: lun-0
spec:
  capacity:
    storage: 50Gi                                 # Match your precise physical LUN size
  volumeMode: Block                               # CRITICAL: Bypasses filesystem node-locking
  accessModes:
    - ReadWriteMany                               # Informs the scheduler multiple nodes can connect concurrently
  persistentVolumeReclaimPolicy: Retain
  storageClassName: scsi-shared-das
  local:
    path: /dev/disk/by-id/scsi-35000c50030142f31  # Target path identical on both nodes
  nodeAffinity:
    required:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - bm208.pietersmalan.com                 # Nodes where luns are available
          - bm209.pietersmalan.com
----


.scsi-shared-das-storageclass.yaml
[source,yaml]
----
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: scsi-shared-das
  annotations:
    storageclass.kubernetes.io/is-default-class: 'true'    # Make storage class default
    storageclass.kubevirt.io/is-default-virt-class: 'true' # Make storage class default for virtualization use
provisioner: kubernetes.io/no-provisioner                  # Instructs OpenShift to look for your static PV
volumeBindingMode: Immediate
----


To determine the devicepaths, do a 'ls /dev/disk/by-id/scsi-*'

== Add Volume Recycler

We need to cleanup the lun after recycling.

We create a listener watching the PVs, and act on a recycle event, which will clean up the lun, reread the partition table as well.

WARNING: Script in the recycler assume the storage class name is defined as "scsi-shared-das" and that the reclaim policy is set to "Retain"

TIP: The reclaim policy set to "Retain" to by the warnings that there are no cleanup available for no-provisioner storage.

.scsi-recycler-role.yaml
[source,yaml]
----
apiVersion: v1
kind: ServiceAccount
metadata:
  name: scsi-recycler-sa
  namespace: openshift-virtualization-os-images
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: scsi-pv-recycler-role
rules:
  - apiGroups: [""]
    resources: ["persistentvolumes"]
    verbs: ["get", "list", "watch", "update", "patch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: scsi-pv-recycler-binding
subjects:
  - kind: ServiceAccount
    name: scsi-recycler-sa
    namespace: openshift-virtualization-os-images
roleRef:
  kind: ClusterRole
  name: scsi-pv-recycler-role
  apiGroup: rbac.authorization.k8s.io
----

.scsi-recycler-sa.yaml
[source,yaml]
----
apiVersion: security.openshift.io/v1
kind: SecurityContextConstraints
metadata:
  name: privileged
users:
- system:serviceaccount:openshift-virtualization-os-images:scsi-recycler-sa

----

.PV recycler
[source,yaml]
----
apiVersion: apps/v1
kind: Deployment
metadata:
  name: scsi-block-recycler
  namespace: openshift-virtualization-os-images
spec:
  replicas: 1
  selector:
    matchLabels:
      app: scsi-block-recycler
  template:
    metadata:
      labels:
        app: scsi-block-recycler
    spec:
      serviceAccountName: scsi-recycler-sa
      hostPID: true
      securityContext:
        seccompProfile:
          type: RuntimeDefault
      containers:
        - name: cycler
          image: quay.io/openshift/origin-cli:latest
          securityContext:
            privileged: true
            allowPrivilegeEscalation: true
            runAsNonRoot: false
            runAsUser: 0
          volumeMounts:
            - name: host-dev
              mountPath: /dev
          command:
            - /bin/bash
            - -c
            - |
              echo "Starting SCSI block storage monitoring loop..."
              while true; do
                # Fetch all PVs formatted as: name phase storageclass
                oc get pv -o jsonpath='{range .items[*]}{.metadata.name}{" "}{.status.phase}{" "}{.spec.storageClassName}{"\n"}{end}' 2>/dev/null | while read -r pv phase st_class; do
                  
                  if [ -z "$pv" ]; then
                    continue
                  fi
                  
                  # Check if the storage class matches AND the phase is either Released or Failed
                  if [ "$st_class" == "scsi-shared-das" ] && { [ "$phase" == "Released" ] || [ "$phase" == "Failed" ]; }; then
                    echo "=================================================="
                    echo "Processing $phase volume: $pv"
                    
                    DISK_PATH=$(oc get pv "$pv" -o jsonpath='{.spec.local.path}' 2>/dev/null)
                    if [ -z "$DISK_PATH" ]; then
                      echo "ERROR: Could not find local path for PV $pv. Skipping."
                      continue
                    fi
                    
                    if [ -b "$DISK_PATH" ]; then
                      echo "Executing: wipefs -af $DISK_PATH"
                      wipefs -af "$DISK_PATH"
                      blockdev --rereadpt "$DISK_PATH" 2>/dev/null || true
                      echo "Device signatures successfully wiped on $DISK_PATH."
                    else
                      echo "WARNING: Block device $DISK_PATH is not visible on this node worker context."
                    fi
                    
                    echo "Fixing reclaim policy and stripping claim locks on $pv..."
                    
                    # 1. Swap policy to Retain so the broken engine drops controller locks
                    oc patch pv "$pv" --type=json -p='[{"op": "replace", "path": "/spec/persistentVolumeReclaimPolicy", "value": "Retain"}]' 2>/dev/null || true
                    
                    # 2. Release the claim allocation links
                    oc patch pv "$pv" --type=json -p='[{"op": "remove", "path": "/spec/claimRef"}]' 2>/dev/null || true
                    
                    # 3. Clean the sticky controller message status
                    oc patch pv "$pv" --subresource=status --type=json -p='[{"op": "remove", "path": "/status/message"}]' 2>/dev/null || true
                    
                    echo "Volume $pv successfully converted to Retain and recycled to Available."
                    echo "=================================================="
                  fi
                done
                sleep 20
              done
      volumes:
        - name: host-dev
          hostPath:
            path: /dev

----
