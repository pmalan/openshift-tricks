:toc-placement!:

If you have shared SCSI luns on an OpenShift cluster and don't have the ability to utilize a CSI complaint provisioner, then you can pre-allocate the PVs and use no-provioner storage class to simulate a CSI provisioner.

WARNING: SCSI-3 Persistent Reservations (PR) are vital when using a raw block ReadWriteMany (RWX) device across multiple OpenShift nodes. They allow application-level clustering software—like Red Hat High Availability (Pacemaker)—to coordinate writes, manage node quorum, and safely fence off unhealthy nodes to prevent split-brain data corruption. 

TIP: On Dell PowerVault storage arrays (including the ME4 and ME5 series), SCSI-3 Persistent Reservations (PR) are natively supported and permanently enabled by default.

== Enable Multipath on Nodes

WARNING: If 2/3 node cluster use master role, instead of worker role.

.99-worker-multipath.yaml
[source,yaml]
----
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: worker
  name: 99-worker-multipath
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        - contents:
            source: data:,defaults%20%7B%0A%20%20%20%20user_friendly_names%20yes%0A%20%20%20%20find_multipaths%20yes%0A%7D%0A
          mode: 420
          filesystem: root
          path: /etc/multipath.conf
    systemd:
      units:
        - enabled: true
          name: multipathd.service
----

== Configure Storage

=== Configure Volume PVs

.scsi-lun0.yaml
[source,yaml]
----
apiVersion: v1
kind: PersistentVolume
metadata:
  name: lun-0
spec:
  capacity:
    storage: 50Gi                                 # Match your precise physical LUN size
  volumeMode: Block                               # CRITICAL: Bypasses filesystem node-locking
  accessModes:
    - ReadWriteMany                               # Informs the scheduler multiple nodes can connect concurrently
  persistentVolumeReclaimPolicy: Recycle
  storageClassName: scsi-shared-das
  local:
    path: /dev/disk/by-id/scsi-35000c50030142f31  # Target path identical on both nodes
  nodeAffinity:
    required:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - bm208.pietersmalan.com                 # Nodes where luns are available
          - bm209.pietersmalan.com
----


.scsi-shared-das-storageclass.yaml
[source,yaml]
----
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: scsi-shared-das
  annotations:
    storageclass.kubernetes.io/is-default-class: 'true'    # Make storage class default
    storageclass.kubevirt.io/is-default-virt-class: 'true' # Make storage class default for virtualization use
provisioner: kubernetes.io/no-provisioner                  # Instructs OpenShift to look for your static PV
volumeBindingMode: Immediate
----


To determine the devicepaths, do a 'ls /dev/disk/by-id/scsi-*'

== Exclude scanning of Volumes for LVM

.99-worker-lvm-filter
[source,yaml]
----
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  labels:
    machineconfiguration.openshift.io/role: worker
  name: 99-worker-lvm-filter
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        - path: /etc/lvm/lvm.conf
          mode: 420
          overwrite: true
          user:
            name: root
          contents:
            source: data:,%23%20OpenShift%20LVM%20Configuration%0Adevices%20%7B%0A%20%20%20%20global_filter%20%3D%20%5B%20%22r%7C%5E/dev/disk/by-id/scsi-.*%7C%22%2C%20%22r%7C%5E/dev/sd.*%7C%22%2C%20%22a%7C.*%7C%22%20%5D%0A%7D
----

== (Optionally) Configure Openshift Virtualization


.kubevirt-hyperconverged
[source,yaml]
----
apiVersion: hco.kubevirt.io/v1beta1
kind: HyperConverged
metadata:
  name: kubevirt-hyperconverged
  namespace: openshift-cnv
spec:
  featureGates:
    persistentReservation: true     # <-- Enable this
----
