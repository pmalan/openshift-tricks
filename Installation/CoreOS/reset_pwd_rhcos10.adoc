= Reset / Set Password for Openshift RHCOS

Please note that this only sets the password for *console* access, not for *ssh*.

== Boot into recovery mode


Interrupt the countdown on the boot loader by pressing a key, then on grub menu, press e on default boot item.

Append at the end of the "linux ..." line add the *rd.break*

*Ctrl+X* to boot


== Reset/Set Password

.In the console:
[source,bash]
----
mount -o remount,rw /sysroot
chroot /sysroot
passwd core
chcon -h system_u:object_r:shadow_t:ts0 /etc/shadow
exit
reboot now
----
